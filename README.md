## 👨‍💻 Sobre mí

Ingeniero Informático egresado de la **Universidad Centroamericana José Simeón Cañas (UCA)**, actualmente en la fase final de desarrollo de proyecto de tesis. 

Profesionalmente me desempeño en el área de **Soporte Técnico Corporativo para Tigo El Salvador** (vía outsourcing por Stefanini), gestionando el monitoreo de servicios empresariales, diagnóstico de problemas de conectividad y redes, seguimiento y resolución de incidencias, documentación técnica y articulación con equipos especializados.

Mi perfil profesional combina el análisis e integración de sistemas, gestión y consulta de bases de datos, desarrollo de aplicaciones web mediante APIs REST y soluciones orientadas al análisis de datos y la automatización de procesos.
